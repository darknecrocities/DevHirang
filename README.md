## 🌟 Overview

**DevHirang** is a premium, data-driven platform designed to showcase the elite developers of the community. It goes beyond simple profiles, offering a gamified achievement system, dynamic badging, and a high-fidelity user interface built for the modern web.

## ✨ Key Features

### 🎖️ Dynamic Badge System
A tiered recognition system that automatically awards badges based on developer statistics:
- **World Level**: The pinnacle tier for global influencers (40+ Certs, 10+ Wins, 100+ Projects).
- **Platform Admin**: Exclusive administrative recognition.
- **Legacy Builder**: Rewarding long-term commitment (5,000+ Points).
- **Rising Star**: Highlighting fast-growing talent (1,000+ Points).
- **Specialized Badges**: *Hackathon Hero*, *Product Visionary*, *Elite Contributor*, and *Community Pillar*.

### 📖 Dev Diaries & Premium Achievements
A categorized achievements timeline with:
- **Glassmorphism Design**: High-end visual cards with localized glows.
- **Categorization**: Visual distinctions for Hackathons, Open Source, Community, and Startups.
- **Expandable Views**: State-managed "See More" functionality for clean information density.

### 👤 Interactive Profiles
Rich developer cards and diagnostic modals:
- **Real-time Stats**: Track projects, wins, and community impact.
- **Badge Achievement Guide**: An expandable, instructional view explaining the roadmap to every badge.
- **CTA Integration**: Direct links to GitHub, Portfolios, and professional inquiries.

## 🛠️ Tech Stack

- **Core**: React 19 + Vite 7 (High-performance HMR)
- **Styling**: Tailwind CSS 4 + Glassmorphism / Custom CSS Utilities
- **Animations**: Framer Motion (Smooth layout transitions and micro-interactions)
- **Icons**: Lucide React (Pixel-perfect achievement iconography)
- **State Management**: React Context & Hooks for dynamic UI transitions

## 🚀 Getting Started

### Prerequisites
- Node.js (v18 or higher)
- npm or yarn

### Installation

1. **Clone the repository**
   ```bash
   git clone https://github.com/darknecrocities/DevHirang.git
   cd DevHirang
   ```

2. **Install dependencies**
   ```bash
   npm install
   ```

3. **Launch Development Server**
   ```bash
   npm run dev
   ```

## 🏗️ Architecture

- `/src/data`: Centralized `developers.json` acting as the single source of truth for stats and achievements.
- `/src/utils`: `badgeUtils.js` containing the logic for the dynamic recognition engine.
- `/src/components`: Atomic component structure focused on high-fidelity UI/UX.
